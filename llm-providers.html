مزوّدو الذكاء الاصطناعي القابلون للربط

هذه الصفحة تحوّل دليل Free LLM API Resources إلى دليل عملي لأثَر. المستودع يجمع مزوّدين وشروطهم؛ لا يوفّر مفتاح API موحّدًا ولا يجعل كل خدمة تعمل تلقائيًا.

حالة التكامل الآن: كود صانع الأسئلة يستخدم بوابة خلفية متوافقة مع OpenAI Chat Completions. اختيار مزوّد مجاني لا يفعّل الخدمة وحده؛ يجب إنشاء مفتاح من المزوّد وإضافته إلى أسرار Supabase. لا توجد مفاتيح سرية في المتصفح أو GitHub. المجانية والحصص تتغير، لذا راجع الشروط الرسمية قبل الاستخدام.

طريقة ربط مزوّد في أثَر

  1. اختر مزوّدًا وراجع حدوده الحالية ودعم العربية والنموذج المطلوب.
  2. أنشئ مفتاح API من حسابك لدى المزوّد؛ لا تضعه في ملف HTML أو إعدادات الواجهة.
  3. في Supabase → Edge Functions → Secrets أضف LLM_API_KEY وLLM_BASE_URL وLLM_MODEL، واختياريًا LLM_PROVIDER.
  4. استخدم عنوان API الأساسي الذي توثقه الخدمة، من دون المسار النهائي /chat/completions إذا كانت البوابة تضيفه تلقائيًا.
  5. اختبر توليد أسئلة من نص قصير، ثم راجع كل إجابة قبل اعتمادها.

تفاصيل الإعداد موجودة في دليل المطوّرين. لا تدّعي المنصة أن المزوّد متصل فعليًا إلا بعد ضبط الأسرار واجتياز اختبار حي.
