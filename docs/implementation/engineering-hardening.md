## ما يزال غير جاهز للإطلاق

1. **Supabase:** المشروع `cjccnpwukssimdgnyezi` ما زال `INACTIVE`. لم أستعده ولم أطبق SQL عليه لأن حالة الفوترة/التكلفة لم تتأكد؛ لن أفعّل خدمة قد تنشئ تكلفة دون تأكيد واضح.
2. **المصادقة:** ملف الإعداد لا يزال بلا URL أو publishable key، لذلك تسجيل الدخول ليس جاهزًا للعمل.
3. **التخزين:** سياسات التخزين محفوظة كملف SQL لكنها لم تُطبق أو تُختبر على مشروع فعّال.
4. **المحتوى:** لوحة الإدارة الحالية نموذج محلي؛ اختيار الملف لا يعني رفعه إلى خادم.
5. **الذكاء الاصطناعي:** لم يتم اختيار مزود LLM مجاني موثوق أو ربطه. يجب فحص حدوده وشروطه وخصوصية بياناته قبل الربط.
6. **المستودعات الخارجية:** لم تُثبّت أو تُنسخ ملفات من المستودعات الـ25. يجب فحص الترخيص والاعتماديات والأمان والتوافق أولًا. تعذّر جلب README لمستودع `cheahjs/free-llm-api-resources` عبر الموصل أثناء هذا الفحص، لذا يلزم التحقق من توفره.
