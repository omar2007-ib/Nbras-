## ما تغيّر في فرع التطوير
- إضافة `video-studio.html` و`assets/athar-video-studio.js` و`assets/athar-video-studio.css`: اختيار فيديو محلي، قصّ يدوي، اقتراح نقاط قص عبر فرق الإطارات، إضافة ترجمة نصية يدوية وتصدير SRT، وتسجيل مقطع عمودي 9:16 عبر واجهات المتصفح.
- إضافة `design-studio.html` وملفات CSS/JS الخاصة به: إنشاء تصميم SVG من نص المستخدم، تصديره SVG أو PNG، وتصدير لوحة الهوية بصيغة JSON.
- إضافة روابط الاستوديوهين إلى الصفحة الرئيسية.
- إضافة طبقة ألوان مشتركة للهوية المعتمدة: `#5B21B6` و`#C4B5FD`، وإخفاء الرمز المنفصل من كلمة الشعار مع إبقاء «أثَر» نصًا.
- إضافة `scripts/test_creative_studios.py` وفحوصات بناء JavaScript إلى سيرَي CI.
- تحديث README لتوضيح حدود النسخة الجديدة.

## الخصوصية والحدود الوظيفية
- أداة الفيديو لا ترفع ملف المستخدم إلى خادم ولا تستخدم نقطة API لمعالجة الفيديو؛ المعالجة تتم محليًا.
- اقتراح القص يعتمد على تغيّر الصورة فقط، وليس تحليلًا دلاليًا أو تقييمًا ذكيًا للمحتوى.
- الترجمة النصية يدوية؛ لا توجد خدمة تحويل كلام إلى نص أو ترجمة آلية متصلة.
- محرر التصميم ينشئ رسومات SVG/PNG فعلية من قوالب ثابتة؛ لا يدّعي أنه مولّد صور بالذكاء الاصطناعي.
- لا يحتوي المستودع على ملف خط جزيل المرخّص. لم أضمّن ملفًا تجاريًا غير مرخّص؛ أولوية CSS هي Jazeel عند توفره، لكن يلزم إضافة الملف المرخّص قبل اعتماد الهوية النهائية.
