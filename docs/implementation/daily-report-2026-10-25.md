## الخصوصية والحدود الوظيفية
- أداة الفيديو لا ترفع ملف المستخدم إلى خادم ولا تستخدم نقطة API لمعالجة الفيديو؛ المعالجة تتم محليًا.
- اقتراح القص يعتمد على تغيّر الصورة فقط، وليس تحليلًا دلاليًا أو تقييمًا ذكيًا للمحتوى.
- الترجمة النصية يدوية؛ لا توجد خدمة تحويل كلام إلى نص أو ترجمة آلية متصلة.
- محرر التصميم ينشئ رسومات SVG/PNG فعلية من قوالب ثابتة؛ لا يدّعي أنه مولّد صور بالذكاء الاصطناعي.
- لا يحتوي المستودع على ملف خط جزيل المرخّص. لم أضمّن ملفًا تجاريًا غير مرخّص؛ أولوية CSS هي Jazeel عند توفره، لكن يلزم إضافة الملف المرخّص قبل اعتماد الهوية النهائية.
