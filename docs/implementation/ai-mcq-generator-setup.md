# تفعيل مولّد أسئلة أثَر الذكي

تم نشر Edge Function باسم `generate-mcq` مع التحقق من JWT والتحقق من دور `owner` أو `admin` من جدول `profiles`.

## الإعداد المطلوب مرة واحدة

1. افتح لوحة Supabase للمشروع `cjccnpwukssimdgnyezi`.
2. افتح Edge Functions / Secrets.
3. أضف `OPENAI_API_KEY` بقيمة مفتاح API الخاص بك. لا تضع المفتاح في ملفات HTML أو GitHub.
4. اختياريًا، أضف `OPENAI_MODEL` باسم نموذج متوافق مع واجهة OpenAI Chat Completions. الافتراضي هو `gpt-4o-mini`.
5. تأكد أن حساب المالك/المدير لديه دور `owner` أو `admin` في `public.profiles`، وأن تسجيل الدخول بالبريد يعمل.
6. افتح `mcq-builder.html`، سجّل الدخول، ارفع PDF قابلًا لاستخراج النص أو الصق النص، ثم أنشئ المسودات وراجعها قبل الاعتماد.

## ملاحظات وحدود

- ملفات PDF المصوّرة تحتاج OCR؛ استخراج النص الحالي لا يحوّل صور الصفحات إلى نص.
- التوليد يرسل النص المستخرج إلى مزوّد الذكاء الاصطناعي. لا ترفع مواد لا تملك حق استخدامها.
- تُحفظ الأسئلة المعتمدة حاليًا في تخزين المتصفح المحلي فقط. استخدم تصدير JSON للنسخ الاحتياطي؛ مزامنة بنك الأسئلة بين الأجهزة تحتاج خطوة تطوير منفصلة.
- يجب مراجعة صحة كل إجابة قبل استخدامها في اختبار رسمي.
- إذا لم تتم إضافة `OPENAI_API_KEY`، ستظهر رسالة توضّح أن مولّد الذكاء الاصطناعي غير مفعّل.
