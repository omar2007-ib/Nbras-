# ربط بوت واتساب أثَر

تم نشر Edge Function باسم `athar-whatsapp-webhook` على مشروع Supabase المرتبط بالمنصة.

## ما الذي يفعله؟
- يتحقق من طلب التفعيل GET باستخدام `WHATSAPP_VERIFY_TOKEN`.
- يتحقق من توقيع Meta `X-Hub-Signature-256` باستخدام `META_APP_SECRET`.
- يعالج الرسائل النصية الواردة ويرد بالعربية عبر نفس إعدادات مزوّد الذكاء الاصطناعي في أثَر.
- يسجل معرّف كل رسالة في جدول خاص لمنع الرد المكرر عند إعادة إرسال webhook.
- يحد من الاستخدام لكل رقم عبر دالة حد الاستخدام الموجودة.
- لا يسجل نصوص الرسائل أو أرقام المرسلين في سجلات التشغيل؛ تُحفظ بيانات الرسالة والرد في جدول خاص مفعّل عليه RLS بلا سياسات وصول عامة.

## الأسرار المطلوبة في Supabase
من إعدادات المشروع > Edge Functions > Secrets، أضف القيم التالية دون وضعها في GitHub أو ملفات الواجهة:

- `WHATSAPP_VERIFY_TOKEN`: قيمة عشوائية طويلة تختارها أنت، وتضع القيمة نفسها في إعداد Webhooks في Meta.
- `META_APP_SECRET`: App Secret من تطبيق Meta.
- `WHATSAPP_ACCESS_TOKEN`: رمز وصول صالح لإرسال رسائل WhatsApp Cloud API.
- `WHATSAPP_PHONE_NUMBER_ID`: معرّف رقم الهاتف في WhatsApp Business Platform.
- `WHATSAPP_API_VERSION`: إصدار Graph API مدعوم بحساب Meta (اختياري؛ الافتراضي الحالي في الكود `v23.0`).
- `LLM_API_KEY` مع `LLM_BASE_URL` و`LLM_MODEL`، أو `GROQ_API_KEY` مع إعدادات Groq الاختيارية. يستخدم البوت إعدادات المساعد الحالية نفسها.
- `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` يجب أن يكونا متاحين لبيئة Edge Function.

أدخل نفس قيمة `WHATSAPP_VERIFY_TOKEN` في Meta، ثم فعّل الاشتراك في حقل `messages` ضمن Webhooks الخاص بمنتج WhatsApp. استخدم رقم الاختبار أولًا، وأضف رقم المستلم المسموح به في إعدادات Meta عند الحاجة.

## اختبار آمن
1. اختبر تحقق Meta من callback URL.
2. أرسل رسالة نصية من رقم اختبار مُصرّح به.
3. تحقق من أن webhook يعيد HTTP 200 وأن سجل الرسالة يتحول إلى `sent`.
4. إذا لم يصل رد، راجع سجلات Edge Function وحالة الرصيد لدى مزوّد الذكاء الاصطناعي.
5. لا تعتبر الربط مكتملًا حتى ينجح اختبار إرسال واستقبال حقيقي من Meta.

## ملاحظة الحالة الحالية
الدالة منشورة، والجدول الخاص بسجل الرسائل مضاف. يلزم إدخال أسرار Meta ومزوّد الذكاء الاصطناعي من لوحة التحكم قبل أن يمكن إكمال اختبار واتساب حي. كما أن اختبار المساعد الحي الحالي أعاد خطأ مزوّد 402 (الرصيد أو الحصة)، لذلك يجب معالجة حساب المزوّد قبل اعتماد الردود الفعلية.
