## إصلاحات الكود
1. **توافق التقاط الصوت في Safari:** أضيف مسار `captureSourceAudio()`. يستخدم `HTMLMediaElement.captureStream()` إذا توفرت وأنتجت مسار صوت، وإلا يستخدم `AudioContext.createMediaElementSource()` و`createMediaStreamDestination()` لإضافة الصوت إلى تسجيل الفيديو العمودي.
2. **سلامة التصدير:** يُفعّل AudioContext قبل انتظار seek حتى لا تضيع إشارة تفاعل المستخدم المؤقتة، ويرفض التصدير إذا تعذّر تجهيز مسار صوت بدل إنتاج ملف صامت. أضيف تنظيف لمسار الصوت وAudioContext.
3. **اختبار رجعي فعلي:** اختبار المتصفح يعطّل `HTMLMediaElement.captureStream()` عمدًا ثم يرفع فيديو محليًا ويختبر استيراد SRT وإتمام التصدير عبر مسار Web Audio.
4. **WebKit CI صريح:** فحص WebKit يختبر التخطيط والتركيز، ولا يزعم اختبار التصدير إذا غابت واجهات التسجيل؛ يسجل سبب التخطي بوضوح.
5. **هوية أثَر:** صُحّح ملف Master Design System ليطابق اللونين `#5B21B6` و`#C4B5FD` ويؤكد أن Jazeel هو خط العلامة ولا يجوز استبداله. لم أضف خطًا غير مرخّص.
6. حُدّث README وبحث أدوات الإنتاج لتوثيق حدود Safari وخطة التفريغ الصوتي.

## ما لم يُنفّذ وما يمنع اعتماده
- **التفريغ الصوتي والترجمة التلقائية:** لم تُوصّل بعد. بحثت خيار Transformers.js؛ وثائقه تدعم ASR مع timestamps وchunking، وWhisper متعدد اللغات يصلح لنموذج أولي. يلزم Worker، تنزيل اختياري، قياس الذاكرة والوقت، واختبار لهجات عربية مرخّصة. WebGPU ليس مضمونًا على كل متصفح؛ يجب إبقاء WASM fallback. ترجمة Whisper المدمجة تتجه إلى الإنجليزية، والترجمة إلى العربية تحتاج مرحلة منفصلة.
- **توليد الصور بالذكاء الاصطناعي:** غير متصل. الاستوديو الحالي ينشئ SVG/PNG فعليًا من قوالب ونصوص المستخدم، وليس مولد صور AI. لم أضع مفتاحًا أو استدعاء API وهميًا.
- **جزيل:** لا يوجد ملف Webfont مرخّص داخل المستودع. CSS يطلب Jazeel، لكن لا يمكن تأكيد ظهور الخط الحقيقي في المتصفح أو PNG حتى يضاف ملف الويب المرخّص. لا يُسمح باستبداله بخط آخر.
- **iPad حقيقي:** مسار Web Audio اجتاز اختبار Chromium القسري، لكن Playwright WebKit على Linux لا يوفّر MediaRecorder في بيئته. يلزم اختبار تصدير يحوي صوتًا على Safari في iPad فعلي قبل تأكيد الدعم.
- **FFmpeg.wasm:** لم يُدمج؛ حجمه واستهلاك الذاكرة والبطء المحتمل على الأجهزة المحمولة يستلزمون تحميلًا كسولًا داخل Worker وقياسًا قبل اعتماده.
