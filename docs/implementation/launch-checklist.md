## المطلوب لإكمال الإطلاق
1. سجّل الدخول مرة واحدة من `auth.html` باستخدام البريد الذي تريد اعتماده للمالك، بعد ضبط إعدادات البريد وRedirect URLs في Supabase.
2. بعد إنشاء الحساب، عيّن دور المالك من SQL Editor الموثوق:
   ```sql
   update public.profiles p
   set role = 'owner', updated_at = now()
   from auth.users u
   where p.id = u.id and lower(u.email) = lower('YOUR_OWNER_EMAIL');
   ```
3. اختبر واجهة `admin.html` على بيئة اختبار: رفع PDF وفيديو MP4/WebM وصورة، النشر وإلغاء النشر والحذف، ثم اختبر أن الطالب لا يستطيع إدارة المحتوى أو قراءة المسودات.
4. بعد نجاح الاختبارات، عدّل `scripts/build_static.py` لإدراج لوحة الإدارة في الحزمة العامة؛ لا تدرجها قبل إتمام اختبار الصلاحيات.
5. أعد النشر وتحقق من فتح جميع الصفحات دون 404.
6. الحد الحالي 50 MiB لكل ملف؛ الفيديوهات الأكبر تحتاج رفعاً متدرجاً أو خدمة فيديو مخصصة.
7. مركز الإشعارات الحالي داخل الموقع يحفظ حالة القراءة على الجهاز فقط؛ لا توجد إشعارات خادمية أو push بعد.

## معايير القبول
- تسجيل الدخول بالبريد يعمل فعلياً.
- الصلاحيات تفرضها RLS وسياسات Storage، لا الواجهة وحدها.
- الطالب لا يستطيع تعديل المحتوى أو الوصول إلى الملفات غير المنشورة.
- رفع الملفات وحذفها يعملان على التخزين الخاص.
- جميع الصفحات المنشورة تعمل على الجوال والحاسوب، ولا توجد أخطاء 404.
