# نِبراس — منصة الاستعداد للقدرات

واجهة عربية RTL أولية لمنصة تعليمية للاستعداد لاختبار القدرات الكمي.

## موارد التطوير والمهارات
- [فهرس مستودعات GitHub الـ27 ومقترح اعتمادها](docs/research/github-resources.md) — روابط مهارات التصميم والبرمجة والجودة والأمان ومشاريع التعليم ومصادر LLM.

## الصفحات
- `mcq-builder.html` — أداة يدوية لإنشاء أسئلة اختيار من متعدد وتصديرها/استيرادها
- `design-system/nibras/MASTER.md` — نظام التصميم الرئيسي للمنصة
- `index.html` — الصفحة الرئيسية
- `courses.html` — الدورات
- `practice.html` — تدريب تجريبي من خمسة أسئلة
- `study-plan.html` — قائمة مهام مذاكرة
- `resources.html` — مكتبة المحتوى (هيكل أولي)
- `about.html` — عن المنصة
- `admin.html` — لوحة إدارة محتوى أولية (معاينة فقط)
- `auth.html` — واجهة دخول بالبريد (تحتاج ربط Supabase)
- `supabase/schema.sql` — مخطط قاعدة البيانات وسياسات RLS
- `supabase/README.md` — خطوات إعداد قاعدة البيانات
- `assets/supabase-config.js` و`assets/auth.js` — تهيئة عامة وواجهة الدخول
- `assets/style.css` — التنسيقات المشتركة
- `assets/app.js` — منطق قائمة المهام
- `assets/admin.js` — منطق واجهة الإدارة التجريبية

## تشغيل
افتح `index.html` في متصفح حديث أو انشر المستودع عبر GitHub Pages.

## تنبيه أمني وتشغيلي
`admin.html` ليست محمية بتسجيل دخول. قائمة المحتوى تُحفظ في localStorage على المتصفح الحالي فقط. اختيار الملفات لا يرفعها إلى الخادم، ولا تظهر للطلاب أو على أجهزة أخرى. لا تضع بيانات حساسة ولا تستخدم اللوحة لإدارة فعلية قبل إضافة خادم خلفي، وتسجيل دخول آمن، وصلاحيات مالك/مدير، وتخزين ملفات خاص، والتحقق من الملفات، وسجل تدقيق.

## دورات نبراس
1. تأسيس — «تأسيس من حديد»
2. تدريبات — «الخطوة الأخيرة»

## ما يلزم قبل الإطلاق
قاعدة بيانات، مصادقة وصلاحيات، رفع وتخزين ملفات، استضافة فيديو، إدارة محتوى حقيقية، واختبارات أمنية ووظيفية. لا يوجد تكامل ذكاء اصطناعي فعلي حتى الآن.


## مرحلة ربط الحسابات وقاعدة البيانات
تمت إضافة واجهة دخول وتجهيز أولي لقاعدة بيانات Supabase وسياسات وصول. لم يتم تشغيل المخطط أو ربط الموقع بمشروع فعّال بعد؛ مشروع Supabase المتاح حالياً حالته INACTIVE. لا تعمل واجهة الدخول حتى يتم تفعيل المشروع، وضبط البريد الإلكتروني، وإدخال رابط المشروع وpublishable key في `assets/supabase-config.js`. لا تضع مفاتيح service_role أو المفاتيح السرية في المستودع.
