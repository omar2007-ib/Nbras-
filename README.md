# نِبراس — منصة الاستعداد للقدرات

واجهة عربية RTL أولية لمنصة تعليمية للاستعداد لاختبار القدرات الكمي.

## الصفحات
- `index.html` — الصفحة الرئيسية
- `courses.html` — الدورات
- `practice.html` — تدريب تجريبي من خمسة أسئلة
- `study-plan.html` — قائمة مهام مذاكرة
- `resources.html` — مكتبة المحتوى (هيكل أولي)
- `about.html` — عن المنصة
- `admin.html` — لوحة إدارة محتوى أولية (معاينة فقط)
- `assets/style.css` — التنسيقات المشتركة
- `assets/app.js` — منطق قائمة المهام
- `assets/admin.js` — منطق واجهة الإدارة التجريبية

## تشغيل
افتح `index.html` في متصفح حديث أو انشر المستودع عبر GitHub Pages.

## تنبيه أمني وتشغيلي
`admin.html` ليست محمية بتسجيل دخول. قائمة المحتوى تُحفظ في localStorage على المتصفح الحالي فقط. اختيار الملفات لا يرفعها إلى الخادم، ولا تظهر للطلاب أو على أجهزة أخرى. لا تضع بيانات حساسة ولا تستخدم اللوحة لإدارة فعلية قبل إضافة خادم خلفي، وتسجيل دخول آمن، وصلاحيات مالك/مدير، وتخزين ملفات خاص، والتحقق من الملفات، وسجل تدقيق.

## دورات نبراس
1. تأسيس — «تأسيس من حديد»
2. تدريبات — «الخطوة الأخيرة»

## ما يلزم قبل الإطلاق
قاعدة بيانات، مصادقة وصلاحيات، رفع وتخزين ملفات، استضافة فيديو، إدارة محتوى حقيقية، واختبارات أمنية ووظيفية. لا يوجد تكامل ذكاء اصطناعي فعلي حتى الآن.
