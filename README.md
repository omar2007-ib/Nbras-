# نِبراس — منصة الاستعداد للقدرات

واجهة عربية RTL أولية لمنصة تعليمية للاستعداد لاختبار القدرات الكمي.

## موارد التطوير والمهارات
- [فهرس 25 مستودع GitHub](docs/research/github-resources.md) — روابط مرجعية لمهارات التصميم والبرمجة والجودة والأمان والتعليم ومصادر LLM.
- [حزمة التطوير الجاهزة للاستخدام](docs/IMPLEMENTATION-PACK-AR.md) — تعليمات يمكن نسخها إلى وكيل البرمجة لتطوير المشروع الحالي على مراحل.
- `developer-resources.html` — صفحة داخل الموقع تعرض المستودعات الخارجية مع البحث والتصنيف.
- المهارات المحلية موجودة في `.agents/skills/`. وجود ملف مهارة لا يعني أن كل أداة برمجة ستفعّله تلقائيًا؛ اقرأ `AGENTS.md` أو اطلب من الوكيل قراءة ملفات المهارات صراحةً.

## الصفحات والأدوات
- `index.html` — الصفحة الرئيسية.
- `courses.html` — الدورات.
- `practice.html` — تدريب تجريبي.
- `study-plan.html` — قائمة مهام المذاكرة.
- `resources.html` — مكتبة المحتوى.
- `about.html` — عن المنصة.
- `auth.html` — واجهة دخول تحتاج إلى ربط Supabase نشط.
- `admin.html` — لوحة إدارة محتوى أولية للمعاينة، وليست لوحة إنتاج محمية.
- `mcq-builder.html` — إنشاء أسئلة اختيار من متعدد واستيرادها/تصديرها.
- `developer-resources.html` — فهرس موارد التطوير.
- `design-system/nibras/MASTER.md` — نظام التصميم الرئيسي.
- `AGENTS.md` — تعليمات تطوير آمنة للوكلاء البرمجيين.
- `scripts/check_site.py` و`.github/workflows/site-checks.yml` — فحوص ساكنة للموقع وتشغيلها في GitHub Actions.

## المهارات المحلية
- `nibras-frontend` — واجهة عربية RTL متجاوبة.
- `nibras-qa` — فحص الجودة والسلوك.
- `nibras-security` — مراجعة الأمان.
- `nibras-ai-tutor` — مواصفات المدرس الذكي.
- `nibras-learning-design` — تصميم رحلة التعلم والتدريب.
- `nibras-backend-data` — قاعدة البيانات والمصادقة والملفات.
- `nibras-accessibility` — إمكانية الوصول.
- `nibras-content-quality` — جودة الأسئلة والمحتوى.
- `nibras-release-ops` — التحقق والإطلاق.

## التشغيل
افتح `index.html` في متصفح حديث أو انشر الموقع عبر GitHub Pages بعد التحقق من إعدادات المستودع.

## تنبيه أمني وتشغيلي
- `admin.html` ليست محمية بتسجيل دخول حقيقي. لا تستخدمها لإدارة فعلية قبل بناء صلاحيات خلفية واختبارها.
- `localStorage` يحفظ البيانات على المتصفح الحالي فقط ولا يزامنها بين الأجهزة.
- اختيار الملفات في واجهة تجريبية لا يعني رفعها إلى الخادم أو إتاحتها للطلاب.
- ملفات Supabase الموجودة هي تجهيز أولي وليست دليلًا على اتصال مشروع فعّال. يجب التحقق من حالة المشروع وضبط الإعدادات قبل استخدام المصادقة أو قاعدة البيانات.
- لا يوجد تكامل ذكاء اصطناعي فعلي حتى يتم اختيار مزود وربطه واختباره. لا تضع مفاتيح API أو مفاتيح `service_role` في الواجهة أو المستودع.

## الدورات
1. تأسيس — «تأسيس من حديد».
2. تدريبات — «الخطوة الأخيرة».

## قبل الإطلاق
تحقق من قاعدة البيانات والمصادقة والصلاحيات وتخزين الملفات واختبارات المتصفح والنشر. شغّل `python scripts/check_site.py`، ثم راجع أي إعداد يدوي مطلوب من لوحة الاستضافة أو Supabase.
