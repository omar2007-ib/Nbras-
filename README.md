# أثَر — منصة الاستعداد للقدرات

واجهة عربية RTL أولية لمنصة تعليمية للاستعداد لاختبار القدرات الكمي.

## حالة الجاهزية والتشغيل
- `docs/implementation/launch-checklist.md` — الحالة التي تم التحقق منها وخطوات الإطلاق الآمن.
- تم تطبيق `athar_course_content_and_private_storage` على مشروع Supabase النشط؛ راجع `docs/implementation/launch-checklist.md` للحالة الفعلية.

## موارد التطوير والمهارات
- [فهرس 25 مستودع GitHub](docs/research/github-resources.md) — قائمة مرجعية لمهارات التصميم والبرمجة والجودة والأمان والتعليم ومصادر LLM.
- `developer-resources.html` — صفحة داخل أثَر لعرض مستودعات المهارات والبحث فيها. هذه روابط مرجعية وليست تثبيتًا أو دمجًا تلقائيًا للأكواد.\n- `llm-providers.html` — دليل مزوّدي LLM الرسميين؛ يستند إلى `cheahjs/free-llm-api-resources`، وهو دليل مزوّدين وليس API موحدة.
- صفحة `llm-providers.html` مرتبطة من القائمة الرئيسية، وتعرض مزوّدي الوصول المجاني وأرصدة التجربة مع روابط الوثائق.\n- `supabase/functions/generate-mcq/index.ts` — بوابة LLM قابلة للإعداد عبر `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL`, `LLM_PROVIDER` للمزوّدين المتوافقين مع OpenAI Chat Completions.

## التشغيل والبناء للنشر
- للمعاينة المحلية: افتح `index.html` في متصفح حديث.
- لبناء نسخة استضافة ثابتة: شغّل `python3 scripts/build_static.py`؛ ستُنشأ ملفات الموقع العامة داخل `dist/`.
- إعداد `netlify.toml` جاهز للبناء والنشر على Netlify مع نشر `dist/` فقط، بدل كشف ملفات التوثيق والتطوير ومخططات قاعدة البيانات.
- تتضمن نسخة البناء `admin.html`. الواجهة ليست حدًا أمنيًا بحد ذاتها؛ الاعتماد الأمني على RLS وسياسات Storage في Supabase. يلزم اختبار حساب المالك قبل اعتبار اللوحة جاهزة تشغيليًا.

## تنبيه أمني وتشغيلي
واجهة الإدارة في المستودع تستخدم تسجيل الدخول وتتحقق من دور owner/admin، وتفرض قاعدة البيانات والتخزين الخاص الصلاحيات عبر RLS. لكنها مستبعدة حالياً من حزمة الموقع المنشورة؛ لا تعتبر رفع الملفات متاحاً على الموقع العام حتى إكمال اعتماد حساب المالك واختبار الرفع فعلياً. حد الملف 50 MiB. مركز الإشعارات الحالي محلي على الجهاز وليس إشعارات خادمية أو push.

## ما يلزم قبل الإطلاق
اعتماد حساب المالك، إعداد Redirect URLs والبريد، واختبار الرفع والنشر بحساب مالك وحساب طالب. لوحة الإدارة ضمن البناء؛ لا يُعد الاستخدام مكتملًا حتى اجتياز اختبار الصلاحيات end-to-end. رفع الفيديوهات الأكبر من 50 MiB، سجل التدقيق، والإشعارات الخادمية ما زالت غير مكتملة. كود مولّد الأسئلة متصل بدالة Edge Function قابلة للإعداد، لكن التوليد الحي غير مؤكد حتى إضافة مفتاح مزوّد صالح وإجراء اختبار end-to-end.


## مرحلة ربط الحسابات وقاعدة البيانات
تم تطبيق مخطط المحتوى وسياسات RLS والتخزين الخاص على مشروع Supabase النشط. تم تحديث بناء الموقع ليشمل لوحة الإدارة ودليل مزوّدي LLM. لا أستطيع تأكيد آخر نشر حي من هذه الجلسة لأن اتصال Vercel غير متاح هنا. لا تضع مفاتيح service_role أو المفاتيح السرية في المستودع.
